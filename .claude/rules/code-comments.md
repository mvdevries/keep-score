# Commentaar in code

Plaats geen commentaar in code. Schrijf alleen commentaar wanneer de developer
daar expliciet om vraagt.

Dit geldt voor nieuwe code én voor code die je aanpast: voeg geen toelichting,
geen sectiekoppen, geen "waarom"-blokken en geen docstrings toe uit jezelf.
Ook niet wanneer de omringende code wél veel commentaar bevat — deze regel gaat
boven het gebruikelijke advies om de stijl van bestaande code te volgen.

Laat bestaand commentaar met rust. Het is niet aan jou om het op te ruimen,
tenzij daarom gevraagd wordt, of tenzij een comment door jouw wijziging
feitelijk onjuist wordt — pas hem dan aan of haal hem weg.

Leg uit in je antwoord, niet in het bestand. Als een stuk code toelichting
nodig heeft, zet die in de chat of in de commit-message.
